## 実装方針（設計。Power Appsへ未反映）
1. 既存 `S2_Calendar` の個人表示と登録操作を維持。請求書側では元請・現場・契約・締め期間を選び、**確定した**勤怠と日報をバックエンドで突合せる。予定だけでは請求しない。
2. 契約承認済みの人工換算（日勤・半人工・夜勤）と単価を明細へ適用。数量・単価・金額を請求書画面で照合可能にする。数量修正は理由と監査記録が必要。
3. 契約承認済み経費だけを反映。税率/端数処理/締め日/支払期日は確認済み契約情報を参照し、不足時は確定不可。
4. 日次下書き更新、締め日確定候補生成、経理確認→社長最終承認、PDF原本の版管理。実績キーを永続的に請求済み管理して重複請求を防止。
5. 社員・協力会社・経理・社長の閲覧/更新権限はSharePoint/バックエンドで強制。画面のVisible制御だけをセキュリティとしない。
